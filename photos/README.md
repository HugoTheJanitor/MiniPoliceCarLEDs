# Фотографии и заметки по проекту MiniPoliceLEDs

В этой папке храните фотографии и краткие заметки о сборке/тестировании проекта.

Как добавлять фото

- Загрузите файлы изображений (jpg, png) в эту папку. Рекомендуемая структура имени: `YYYY-MM-DD_краткое-описание.jpg` (например: `2026-08-06_mini_police_front.jpg`).
- В корневом README или в любом Markdown-файле проекта вставляйте изображения так:

```markdown
![Краткое описание](photos/2026-08-06_mini_police_front.jpg)

Описание: Здесь вы можете написать, что изображено на фото, какие изменения были сделаны и какие детали важны.
```

Советы

- Если фото очень большие, уменьшите их перед загрузкой (например до ширины 1200px или меньше) чтобы репозиторий не раздувался.
- Для подписи под фото используйте простой текст под изображением.
- Укажите лицензию на свои фото, если хотите разрешить другим использование (например: CC BY-SA или "All rights reserved").

Пример записи с фото

```markdown
![Собранная макетка спереди](photos/2026-08-06_mini_police_front.jpg)
Собрал на макетной плате, запитал от 5V, использовал резисторы 220 Ом для светодиодов.
```
